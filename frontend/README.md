# LeafLens Frontend

Web user interface for LeafLens: Explainable Disease Detection in Turmeric and Citrus Crops.

## Tech Stack
- React 18+
- Vite
- Vanilla CSS with CSS custom properties (design system)
- Lucide React icons

## Development
```bash
npm install
npm run dev
```
The development server proxies `/api` requests to the FastAPI backend running on `http://127.0.0.1:8000`.
